# Articulated zombie models

Adds 28 custom item-display part models and seven item-atlas textures for seven complete zombie designs. Existing fallback armor, masks, keys and Frostbite assets are preserved. Requires BlinkZombie 0.3.3 to animate the parts. The automatic manifest supplies this pack without server configuration changes.

Nearby rigs use six visual entities plus the original zombie AI/hitbox. Default global cap 16, range 28 blocks; distant mobs retain the armor appearance. Rigs are only used when everyone in their world has loaded the plugin pack. In-game fit and performance need validation on the server.
